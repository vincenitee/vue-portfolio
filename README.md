# Vue Portfolio

A personal developer portfolio built with Vue 3 and Vite. It presents a single-page, terminal/dashboard-inspired layout with a sidebar navigation, hero introduction, stats, services, project showcase, tech stack, and a contact section.

## Features

- **Sidebar & mobile nav** — responsive navigation that adapts between desktop sidebar and mobile menu
- **Hero** — introduction/landing section
- **Stats row** — key highlights or metrics
- **Services** — cards describing offered services
- **Project logs** — showcase of projects with detail cards
- **Tech stack** — row of technology icons/tags (PHP, JavaScript, Laravel, Vue, Tailwind CSS, MySQL, Supabase, Git, and more)
- **Contact terminal** — terminal-styled contact section
- **Theme toggle** — light/dark mode switching

## Tech Stack

- [Vue 3](https://vuejs.org/) (`<script setup>` SFCs)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)

## Getting Started

```bash
npm install
npm run dev      # start the dev server
npm run build    # build for production
npm run preview  # preview the production build
```
